# Empleo en Chile

Tendencias de largo plazo del mercado laboral chileno con Casen (1990–2024) y ENE (2010–2026).

- `ENE/descarga_ene.do`: descarga y actualiza los microdatos de la ENE desde el INE.
- `ENE/replicaciones/`: scripts (Python/Stata), series en CSV y gráficos.
- `LOG.md`: hoja de ruta y log del proyecto.

Las bases de datos no se versionan; viven en Dropbox `JRT/Trabajo/BBDD Encuestas`.
